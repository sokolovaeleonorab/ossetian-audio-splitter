Основная задача — получить набор небольших аудиофрагментов, которые затем можно использовать для создания речевого датасета: прослушивать, расшифровывать и сопоставлять с текстом.

##Что делает программа

Загружает исходный аудиофайл.
Ищет участки, где есть речь.
Определяет паузы между речевыми фрагментами.
Разрезает аудио на отдельные части.
Сохраняет каждый фрагмент в папку clips.
Создаёт таблицу metadata.csv с информацией о каждом фрагменте.

Подготовка аудио

Исходный аудиофайл должен быть в формате WAV.

Желательно привести его к формату: mono, 16 kHz, wav

Например, через ffmpeg: ffmpeg -i input.mp4 -ac 1 -ar 16000 data/ossetian_audio_16k.wav

Установка

Перед запуском нужно установить зависимости: pip install -r requirements.txt

Также на компьютере должен быть установлен ffmpeg.

Запуск

Исходный файл нужно положить в папку data и назвать:

ossetian_audio_16k.wav

После этого запустить скрипт:

python split_by_pauses.py
Результат работы

После запуска появятся:

clips/

В этой папке будут отдельные аудиофрагменты:

clip_000001.wav
clip_000002.wav
clip_000003.wav

Также появится файл:

results/metadata.csv

В нём сохраняется информация о каждом фрагменте:

id,audio_path,start_sec,end_sec,duration_sec
Основные параметры

В файле split_by_pauses.py можно менять параметры нарезки:

MIN_SILENCE_LEN = 70
SILENCE_THRESH = -40
KEEP_SILENCE = 200
MAX_CHUNK_LEN = 12_000
MIN_CHUNK_LEN = 1_000

MIN_SILENCE_LEN — минимальная длина паузы.
Например, 70 означает 70 миллисекунд, то есть 0.07 секунды.

SILENCE_THRESH — уровень громкости, ниже которого звук считается тишиной.

KEEP_SILENCE — небольшой запас до и после фразы, чтобы не обрезать начало или конец слова.

MAX_CHUNK_LEN — максимальная длина одного фрагмента. Сейчас стоит 12 секунд.

MIN_CHUNK_LEN — минимальная длина фрагмента. Слишком короткие куски не сохраняются.

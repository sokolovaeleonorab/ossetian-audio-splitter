Основная задача — получить набор небольших аудиофрагментов, которые затем можно использовать для создания речевого датасета: прослушивать, расшифровывать и сопоставлять с текстом.

ЧТО ДЕЛАЕТ ПРОГРАММА

Загружает исходный аудиофайл.
Ищет участки, где есть речь.
Определяет паузы между речевыми фрагментами.
Разрезает аудио на отдельные части.
Сохраняет каждый фрагмент в папку clips.
Создаёт таблицу metadata.csv с информацией о каждом фрагменте.

ПОДГОТОВКА АУДИО

Исходный аудиофайл должен быть в формате WAV.

Желательно привести его к формату: mono, 16 kHz, wav

Например, через ffmpeg: ffmpeg -i input.mp4 -ac 1 -ar 16000 data/ossetian_audio_16k.wav

УСТАНОВКА

Перед запуском нужно установить зависимости: pip install -r requirements.txt
Также на компьютере должен быть установлен ffmpeg.

## Описание алгоритма

Алгоритм предназначен для подготовки речевого датасета на осетинском языке. На вход подаются два файла: исходная аудиозапись в формате WAV 16 kHz mono и чистый осетинский текст, соответствующий этой аудиозаписи.

Общая логика работы построена по аналогии с подходом Айгиза Кунафина: сначала аудио распознаётся моделью, затем из результата распознавания извлекаются слова с таймкодами, после этого слова группируются во фразы, а найденные фразы сопоставляются с заранее подготовленным чистым текстом.

Алгоритм выполняет следующие шаги:

1. Загружается исходный аудиофайл `narty_16k.wav`.

2. Загружается чистый осетинский текст `clean_ossetian.txt`. Текст предварительно приводится к формату, где одна строка соответствует одному предложению или смысловой фразе.

3. Аудиофайл передаётся в модель автоматического распознавания речи `facebook/mms-1b-all`. Для осетинского языка используется языковой код `oss`.

4. Модель распознаёт речь и возвращает слова с временными метками: временем начала и временем конца каждого слова.

5. Полученные слова группируются во фразы. Если пауза между соседними словами меньше 0.5 секунды, слова относятся к одной фразе. Если пауза больше 0.5 секунды, начинается новая фраза.

6. После группировки получается набор распознанных фраз с таймкодами: текст фразы, время начала и время конца в аудиофайле.

7. Далее распознанные фразы сопоставляются с чистым осетинским текстом. Так как модель может распознавать осетинскую речь с ошибками, используется не точное совпадение строк, а коэффициент похожести `similarity`.

8. Для каждого предложения из чистого текста алгоритм ищет наиболее похожую распознанную фразу или несколько соседних фраз. Если похожесть выше заданного порога, предложение считается сопоставленным с найденным участком аудио.

9. По найденным таймкодам исходный аудиофайл нарезается на отдельные `.wav`-фрагменты.

10. В результате формируется датасет: отдельные аудиофрагменты и таблицы с метаданными.

На выходе создаются:

* `data/dataset/wavs/` — папка с нарезанными аудиофрагментами;
* `data/dataset/metadata.csv` — простая таблица для датасета;
* `data/dataset/metadata_full.csv` — расширенная таблица с чистым текстом, распознанным текстом, временем начала и конца, длительностью фрагмента и значением `similarity`.

Показатель `similarity` используется как предварительная автоматическая оценка качества сопоставления. Чем выше значение, тем сильнее совпадают чистый текст и текст, распознанный моделью. При этом низкое значение `similarity` не всегда означает ошибку нарезки, потому что модель может неточно распознавать осетинскую речь. Поэтому итоговое качество датасета нужно дополнительно проверять вручную.
